## Variables ##

**Nanoparticle concentration (N)**
Units: particles / ml<br>

**Available receptor concentration (R)**
Units: receptors / cell<br>

**Bound nanoparticle-receptor complexes (B)**
Units: complexes / cell<br>

**Internalised nanoparticles (I)**
Units: particles / cell<br>

**Senescent cell population (S)**
Units: cells<br>

## Parameters ##

**Binding rate constant (k<sub>on</sub>)**
Units: M<sup>-1</sup>h<sup>-1</sup><br>

**Dissociation rate constant (k<sub>off</sub>)**
Units: h<sup>-1</sup><br>

**Endocytosis rate (k<sub>e</sub>)**
Units: h<sup>-1</sup><br>

**Cell-clearance rate (k<sub>kill</sub>)**
Units h<sup>-1</sup><br>
